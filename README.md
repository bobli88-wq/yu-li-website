## Working on another computer
1. Install **GitHub Desktop** and sign in.
2. **File → Clone repository →** `bobli88-wq/yu-li-website`.
3. Install the **Claude desktop app**, open the **Code** tab and choose the cloned folder.
4. Every time: **Fetch/Pull** before you start, then **Commit + Push** when you're done.
